One editorial page for Friday 20 November 2026: the ICJ's genocide finding against Myanmar, the Shenzhen
declaration, the AI sell-off, the missile that hit Riyadh's PIF tower, and the rest of the day.

`page/` holds the HTML and its data, `tools/render.mjs` rasterises it to `assets/entry.png` with headless Chrome,
and `main.ts` copies that image to `/output/entry.png` for the grader.
